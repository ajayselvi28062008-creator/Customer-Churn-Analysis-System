# Customer Churn Analysis System

## Introduction

The Customer Churn Analysis System is a data analytics project that focuses on identifying customers who are likely to stop using a company's services.
By analyzing customer behavior, demographics, subscription details, and service usage patterns, the system helps businesses understand churn trends and improve customer retention strategies.

## Objectives

* Analyze customer behavior and churn patterns.
* Identify factors influencing customer attrition.
* Compare churned and retained customers.
* Generate business insights through visualizations.
* Support customer retention decision-making.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset Features

The dataset includes customer-related information such as:

* Customer ID
* Gender
* Age
* Tenure
* Monthly Charges
* Total Charges
* Contract Type
* Internet Service
* Payment Method
* Churn Status

## Data Analysis Process

**Data Cleaning**

* Handling missing values
* Removing duplicate records
* Data type conversion

**Exploratory Data Analysis (EDA)**

* Customer demographic analysis
* Service usage analysis
* Contract and payment analysis
* Churn behavior analysis
